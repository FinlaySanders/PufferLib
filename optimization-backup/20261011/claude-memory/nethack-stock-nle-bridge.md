fields. Consequences with plain stubs (found one stall at a time via NH_STOCK_DEBUG=600):
- nle_peaceful_at=0 -> policy walks into peacefuls, "Really attack?" cancelled forever. Emulated from
  stock screen_descriptions ("peaceful X"/"tame X").
- nle_terrain_underfoot=0 -> DOWN/UP masked (stuck on dlvl 1) and door-diagonal spam. Emulated by
  per-level terrain memory of cmap glyphs + "staircase down here" messages.

  per-level floor-object memory (obj/body glyphs) + "You see here" parse; cleared on pickup/eat messages
  (stale memory = ','/'p' zero-time loop).
